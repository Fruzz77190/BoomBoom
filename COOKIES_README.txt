# Exportez vos cookies YouTube (optionnel, si erreur HTTP 403)
#
# Methode simple avec l extension de navigateur "Get cookies.txt LOCALLY" :
# 1. Installez l extension dans Chrome ou Edge
# 2. Allez sur https://www.youtube.com (connecte a votre compte)
# 3. Cliquez sur l extension > Export > copiez le contenu
# 4. Collez dans un fichier nomme cookies.txt dans CE dossier (BoomBoom-main)
# 5. Relancez reparer_mp3_manquants.bat
#
# Fermez Chrome/Edge avant de lancer la reparation (Windows verrouille parfois les cookies).
